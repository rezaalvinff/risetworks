Kebijakan privasi

File skripsi Anda tidak dikirim ke server

Pemeriksaan file skripsi (Word maupun PDF) dan pembuatan file bercatatan semuanya berjalan di browser Anda (HP atau laptop). Isi skripsi tidak diunggah, tidak disimpan, dan tidak bisa kami baca.

Yang dikirim ke server

  • File pedoman kampus (Word atau PDF): teks pedoman dikirim ke server lalu dibaca oleh AI (Google Gemini) untuk diambil aturan formatnya. Untuk pedoman hasil scan yang kecil, file PDF pedomannya yang dikirim. Pedoman dan aturan hasilnya tidak disimpan di server kami.
  • Kode premium yang Anda masukkan, untuk dicek keabsahannya.
  • Alamat IP, hanya untuk membatasi penyalahgunaan (misalnya batas baca pedoman per hari). Catatan ini dihapus otomatis setelah 2 hari.

Yang disimpan di perangkat Anda

Tidak ada. Aturan pedoman yang sudah dibaca hanya diingat selama tab browser terbuka, lalu hilang saat tab ditutup.

WhatsApp

Tombol WhatsApp membuka chat dengan pesan berisi ringkasan hasil cek (skor dan judul temuan). Pesan baru terkirim kalau Anda sendiri menekan kirim. File skripsi baru kami terima kalau Anda mengirimkannya sendiri lewat chat untuk jasa rapikan.

Kontak

Pertanyaan soal privasi bisa disampaikan lewat WhatsApp di halaman utama.
