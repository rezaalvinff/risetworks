Kebijakan privasi

File skripsi Anda tidak dikirim ke server

Pemeriksaan file .docx, pencocokan nomor halaman dari PDF skripsi, dan pembuatan file bercatatan semuanya berjalan di browser Anda (HP atau laptop). Isi skripsi tidak diunggah, tidak disimpan, dan tidak bisa kami baca.

Yang dikirim ke server

  • PDF pedoman kampus (kalau Anda memakainya): teks pedoman dikirim ke server lalu dibaca oleh AI (Google Gemini) untuk diambil aturan formatnya. Untuk pedoman hasil scan yang kecil, file PDF pedomannya dikirim. Aturan hasilnya disimpan supaya tidak perlu dibaca ulang. Kalau Anda mencentang "bagikan", aturan tersebut bisa dipakai pengguna lain.
  • Kode premium yang Anda masukkan, untuk dicek keabsahannya.
  • Laporan pedoman salah beserta alasan yang Anda tulis.
  • Alamat IP, hanya untuk membatasi penyalahgunaan (misalnya batas baca pedoman per hari). Catatan ini dihapus otomatis setelah 2 hari.

Yang disimpan di perangkat Anda

Pilihan pedoman terakhir disimpan di browser Anda supaya tidak perlu memilih ulang. Anda bisa menghapusnya dengan membersihkan data situs.

WhatsApp

Tombol WhatsApp membuka chat dengan pesan berisi ringkasan hasil cek (skor dan judul temuan). Pesan baru terkirim kalau Anda sendiri menekan kirim. File skripsi baru kami terima kalau Anda mengirimkannya sendiri lewat chat untuk jasa rapikan.

Kontak

Pertanyaan soal privasi bisa disampaikan lewat WhatsApp di halaman utama.
