        Apakah file saya disimpan?

        Tidak. File diperiksa di browser Anda sendiri dan tidak dikirim ke mana pun. Lihat kebijakan privasi.

        Lebih baik upload Word atau PDF?

        Keduanya bisa. File Word (.docx) diperiksa lebih lengkap (termasuk track changes, spasi ganda, dan posisi judul tabel) dan bisa dibuatkan file bercatatan. File .doc lama: buka di Word lalu Save As .docx.

        Pedoman saya disimpan?

        Tidak. Isi pedoman hanya dibaca AI untuk diambil aturan formatnya (10 sampai 30 detik), lalu tidak disimpan.
